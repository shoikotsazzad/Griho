# Griho

Bangladesh's first certified used flat marketplace.

A static marketing/landing website built with React + Vite + Tailwind CSS + Framer Motion.

## Features

- Certified flat listings with A–D grading system
- 6-step inspection process visualization
- Fractional ownership investment flow
- Browse 20 certified flat listings (demo data)
- List your flat — multi-step form
- About page with team & roadmap
- Fully responsive, mobile-friendly design

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React
- React Router DOM v7

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
